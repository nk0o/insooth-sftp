# Insooth visual direction

Remember only. Do not write this into the styleguide, ap-layout.css, or other project docs unless the user asks.

Direction: a minimal technical gallery where precise engineering and the value of the journey coexist, laid out like a journal/magazine.

Reference: the attached travel brochure / magazine sheet (Travel Brochure, Travele, Explore). Use the editorial structure — cover, contents, asymmetric spreads, captions, white paper, photography as the color. Keep Insooth restraint: black/white/gray, one accent per screen, specs in captions, Pretendard for body and UI, serif only as an English display point.

The main page (index.html) will be revised later. Existing ap-layout.css tokens already fit this direction.
